دليل استخدام أجندة المدير العام

نظام متابعة المهام والأعمال الخاصة بالمدير العام — جمعية البلاغ المبين الكويتية

1️⃣ البدء السريع

  1. افتح الملف index.html في المتصفح (Chrome أو Edge مفضل).
  2. اضغط زر «＋ مهمة جديدة» أعلى الشاشة.
  3. اكتب عنوان المهمة واختر التصنيف والأولوية والتاريخ والوقت.
  4. عند الحاجة حدّد «بانتظار إجراء من» لتسجيل الجهة التي تنتظر ردها.
  5. اضغط «حفظ المهمة» — تُحفظ تلقائيًا على الجهاز.

2️⃣ الواجهات الرئيسية

  • لوحة التحكم: مؤشرات ورسوم بيانية لجميع المهام.
  • مهامي اليومية: مهام اليوم فقط.
  • المهام القادمة: المجدولة للأيام القادمة.
  • المهام المتأخرة: التي تجاوزت موعدها ولم تُنجز.
  • بانتظار إجراء: المعاملات المعلّقة لدى جهة أخرى.
  • المهام المكتملة: أرشيف الأعمال المنجزة.
  • التقارير: ملخص يومي وأسبوعي وشهري قابل للطباعة والتصدير.

3️⃣ إدارة المهمة

  • ✔ إنجاز: ينقل المهمة إلى الأرشيف مع تسجيل وقت الإنجاز.
  • ⏩ تأجيل: يؤجل المهمة ليوم أو أسبوع أو تاريخ تختاره، ويحسب عدد مرات التأجيل.
  • ✏️ تعديل و 🗑️ حذف.
  • ضع ملاحظاتك في حقل «الملاحظات» لكل مهمة.

4️⃣ التنبيهات (إشعار + صوت)

  1. من «الإعدادات» فعّل الإشعارات ووافق على طلب المتصفح.
  2. فعّل الصوت وحدد وقت التذكير اليومي.
  3. عند إضافة مهمة بوقت محدد فعّل «تذكير بموعد المهمة».
  4. يجب أن يبقى التطبيق مفتوحًا (ولو في الخلفية) لتعمل التنبيهات.

5️⃣ تحليل الشيتات

  1. ادخل «تحليل الشيتات» وارفع ملف xlsx أو csv.
  2. يتعرف النظام على نوع كل عمود (تصنيف / رقم / تاريخ / نص) ويقرأ الأسماء العربية.
  3. تظهر مؤشرات و10 رسوم بيانية مختلفة تلقائيًا.
  4. استخدم الفلاتر لتصفية البيانات وستتحدث الرسوم فورًا.
  5. يمكنك استيراد بيانات الشيت كمهام داخل النظام.

6️⃣ الإعدادات والبنود

  • إضافة / تعديل / حذف التصنيفات.
  • إضافة جهات «بانتظار إجراء من».
  • إضافة بنود وحقول جديدة للمهمة مستقبلًا (نص، رقم، تاريخ، قائمة).
  • إضافة أولويات وحالات جديدة.

7️⃣ النسخ الاحتياطي والنقل

  1. الإعدادات ← «تنزيل نسخة احتياطية».
  2. انقل ملف JSON للجهاز الآخر.
  3. افتح التطبيق هناك ← «استعادة نسخة احتياطية».
  4. اختر «استبدال» أو «دمج».

8️⃣ استخدامه على الهاتف

  • ارفع مجلد التطبيق على استضافة (مثل موقع الجمعية أو GitHub Pages أو Netlify).
  • افتح الرابط من الهاتف ← قائمة المتصفح ← «إضافة إلى الشاشة الرئيسية».
  • سيعمل كتطبيق مستقل بأيقونة الجمعية وحتى بدون إنترنت.
  • لنقل بياناتك من الكمبيوتر استخدم النسخة الاحتياطية.
